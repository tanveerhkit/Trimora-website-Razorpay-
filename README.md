## Included Files

- `home.md`
- `about.md`
- `contact.md`
- `privacy-policy.md`
- `terms.md`
- `refund-cancellation-policy.md`
- `service-fulfillment-policy.md`

## Before Publishing

Replace these placeholders across the files:

- `[Legal Business Name]`
- `[Support Email]`
- `[Support Phone]`
- `[Business Address]`
- `[City, State, India]`
- `[Effective Date]`
